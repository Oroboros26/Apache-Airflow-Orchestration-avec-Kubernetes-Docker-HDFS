1. Contexte professionnel
Mission
Vous êtes Lead Data Engineer à l’Agence Régionale de Santé (ARS) Occitanie, basée à
Montpellier. L’ARS Occitanie coordonne un réseau de 150 médecins sentinelles répartis
sur les 13 départements de la région (09, 11, 12, 30, 31, 32, 34, 46, 48, 65, 66, 81, 82).
Ces médecins transmettent chaque semaine, via le réseau national SurSaUD
(Surveillance Sanitaire des Urgences et des Décès), le nombre de passages aux urgences
et de consultations SOS Médecins pour plusieurs syndromes : grippe, gastro-entérite
aiguë, syndrome grippal, bronchiolite (nourrissons), covid-19.
Chaque semaine, le service épidémiologie de l’ARS doit :
1. Collecter les données brutes de SurSaUD via l’API Santé Publique France
2. Agréger les cas par pathologie, par département et par semaine épidémiologique
(format ISO : YYYY-SXX)
3. Calculer des indicateurs statistiques permettant de détecter une tendance anormale :
taux d’incidence pour 100 000 habitants, z-score par rapport aux mêmes semaines sur
les 5 dernières années, estimation du R0 par modèle SIR simplifié
4. Alerter les décideurs régionaux 48 heures avant que les seuils officiels nationaux ne
soient dépassés, en croisant les données syndromiques avec les données
météorologiques (température, humidité — facteurs aggravants connus)
5. Archiver les données brutes et les rapports dans un volume Docker persistant
pendant une durée minimale de 5 ans, conformément aux obligations légales relatives
aux données de santé publique

Problématique technique
L’ancienne infrastructure reposait sur des scripts Bash planifiés via cron et une base
MySQL locale. Les limites sont atteintes :
Résilience nulle : si la machine tombe, le pipeline s’arrête
Scalabilité absente : les calculs statistiques sur 5 ans de données prennent 3 à 4
heures sur un seul cœur
Traçabilité insuffisante : impossible de rejouer un pipeline pour une semaine passée
RGPD non satisfait : les données de santé doivent être cloisonnées, chiffrées,
accessibles uniquement aux personnes habilitées

Stack technique cible
Vous devez concevoir et déployer une data platform reposant sur :
Docker Compose pour l’orchestration des services : chaque service tourne dans un
conteneur isolé, les données sensibles ne persistent que dans des volumes nommés
Apache Airflow 2.8 avec CeleryExecutor pour l’orchestration déclarative des
pipelines — chaque tâche s’exécute dans un worker Celery dédié
DockerOperator pour les tâches de traitement intensif (calculs statistiques, appels
API) dans des conteneurs dédiés avec leurs propres dépendances Python
Volume Docker nommé pour le stockage des archives brutes et des rapports, avec
partitionnement temporel (/data/ars/raw/<annee>/<semaine>/)

4.4 Indicateurs à calculer
Valeur IAS hebdomadaire pour Occitanie :
valeur_ias_semaine = moyenne(Loc_Reg76) sur les jours de la semaine
ISO

Z-score épidémique (méthode OMS adaptée) :
z = (valeur_ias_semaine - moyenne_historique) / ecart_type_historique

où moyenne_historique et ecart_type_historique sont calculés sur les colonnes
Sais_2019_2020 à Sais_2023_2024 pour les mêmes jours de la semaine (minimum 3
saisons requises).
Estimation du R0 simplifié (modèle SIR) :
R0_estimé = 1 + (taux_croissance_hebdomadaire *
durée_infectieuse_jours / 7)

avec durée_infectieuse_jours = 5 pour la grippe, 3 pour la gastro-entérite, où
taux_croissance_hebdomadaire est calculé sur les 4 dernières valeurs IAS
hebdomadaires disponibles en base.

def calculer_zscore(
valeur_actuelle: float, historique: list[float]
) -> Optional[float]:
"""
Calcule le z-score de la valeur IAS par rapport aux saisons
historiques.
Requiert au minimum 3 valeurs historiques.
"""
valeurs_valides = [v for v in historique if v is not None]
if len(valeurs_valides) < 3:
logger.warning(f"Historique insuffisant
({len(valeurs_valides)} saisons)")
return None
moyenne = np.mean(valeurs_valides)
ecart_type = np.std(valeurs_valides, ddof=1)
if ecart_type == 0:
return 0.0
return float((valeur_actuelle - moyenne) / ecart_type)

def calculer_r0_simplifie(

duree_infectieuse: int = 5,
) -> Optional[float]:
"""Estimation du R0 par calcul du taux de croissance moyen sur les
séries IAS."""
series_valides = [v for v in series_hebdomadaire if v is not None
and v > 0]
if len(series_valides) < 2:
return None
croissances = [
(series_valides[i] - series_valides[i - 1]) / series_valides[i
- 1]
for i in range(1, len(series_valides))
]
if not croissances:
return None
return max(0.0, float(1 + np.mean(croissances) *
(duree_infectieuse / 7)))
